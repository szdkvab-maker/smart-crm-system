# Демонстрационные данные SmartCRM

Добавлена Django-команда `seed_demo`, создающая **10 вымышленных клиентов, 12 сделок и 18 задач** с разными статусами, суммами, приоритетами и сроками.

## Первый запуск (Windows PowerShell)

```powershell
python manage.py migrate
python manage.py createsuperuser
python manage.py seed_demo --username ВАШ_ЛОГИН
python manage.py runserver
```

Если администратор уже существует, пропустите `createsuperuser`. Если в базе только один активный суперпользователь, можно запустить `python manage.py seed_demo` без `--username`.

Войдите в CRM под указанным аккаунтом: данные сразу появятся на дашборде, в списках клиентов, сделок и задач.

**Важно:** команда нужна только один раз на каждую базу данных. SQLite хранит данные между запусками `runserver`. При повторном выполнении команда не создаёт дубликаты записей с тем же владельцем, клиентом и названием. Она не удаляет и не перезаписывает существующие записи. Если вы удалили `db.sqlite3` или используете новую базу, выполните команду заново.

Данные полностью вымышленные. Не используйте их как реальные показатели бизнеса или исторический throughput для лабораторной №6.
