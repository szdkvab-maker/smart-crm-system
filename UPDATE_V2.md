# Обновление SmartCRM до UI V2

Эта версия обновляет интерфейс и добавляет карточки людей и компаний с фото.
Все команды выполняются в PowerShell, в папке smart-crm-system.
Архив не содержит базу данных, виртуальное окружение, фото или .git.

## 1 Остановите сервер и сделайте резервную копию

В терминале с runserver нажмите Ctrl+C. Не закрывайте другие приложения принудительно.

```powershell
git branch --show-current
```

Ожидаемая ветка: feature/smartcrm-ui-v2. Если указана другая ветка, сначала
уточните, где находятся ваши изменения. Не используйте reset или force push.

Сохраните полную копию проекта рядом с ним (может занять время из-за .venv):

```powershell
$crmBackup = Join-Path (Split-Path $PWD.Path -Parent) ("smart-crm-backup-" + (Get-Date -Format "yyyyMMdd-HHmmss"))
Copy-Item -LiteralPath $PWD.Path -Destination $crmBackup -Recurse
Write-Output $crmBackup
```

Это копирует исходники, базу, фото и конфигурацию Git. Если копирование сообщило
об ошибке, не продолжайте обновление до проверки резервной копии.

## 2 Перенесите файлы

Распакуйте архив в отдельную папку. Скопируйте его содержимое в существующую
папку smart-crm-system с заменой одноимённых файлов. Не удаляйте проект,
.venv, db.sqlite3, media/ и .git. manage.py должен остаться в корне проекта.
Архив основан на первой версии MVP; если вы меняли исходники самостоятельно,
сначала сравните их с обновлением, чтобы не затереть свою работу.

## 3 Установите зависимости и примените миграцию

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py test
.\.venv\Scripts\python.exe manage.py runserver
```

Каждую команду выполняйте после успешного завершения предыдущей.
При ошибке остановитесь и сохраните её текст.
Не запускайте createsuperuser повторно: существующий аккаунт сохраняется.
Миграция 0002 добавляет поля, не удаляя клиентов, сделки или задачи.
У старых клиентов появится тип «Человек»; при необходимости вручную выберите «Компания».

## 4 Проверьте в браузере

Откройте http://127.0.0.1:8000/ и обновите страницу Ctrl+F5.
Проверьте существующие записи, добавьте вымышленного клиента, загрузите JPG/PNG/WebP
до 5 МБ, откройте карточку по клику, смените тему и проверьте узкое окно.
Смена темы хранится только в браузере. Без JavaScript карточка откроется отдельной страницей.

Все данные остаются на компьютере. Обновление ничего не отправляет в GitHub.
Сначала проверьте результат, затем отдельно оформляйте коммит и Pull Request.
Не объединяйте и не удаляйте ветки для установки этого архива.

## Если нужно вернуться к первой версии

Остановите сервер. Сохраните текущую папку отдельно и восстановите полную
резервную копию проекта, а не только исходники: база и файлы должны соответствовать
одной версии. Не удаляйте текущие данные без проверки копии.
